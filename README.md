# Список задач (To-Do List)

Аккуратный список задач на чистом HTML, CSS и JavaScript: без фреймворков, без сборки и без зависимостей.

**Демо:** https://ferrrrrrry.github.io/todolist/

## Возможности

**По заданию**
- ✅ Добавление задач (Enter или кнопка «Добавить»; пустой ввод отклоняется)
- ✅ Отметка выполненных задач
- ✅ Удаление задач
- ✅ Сохранение после обновления страницы (`localStorage`)

**Сверх задания**
- Редактирование задачи двойным кликом (Enter — сохранить, Esc — отменить)
- Отмена удаления: уведомление с кнопкой «Отменить» и <kbd>Ctrl/⌘ + Z</kbd>
- Фильтры «Все / Активные / Готово» со счётчиками; фильтр сохраняется в адресе (`#/active`)
- Прогресс-бар, «Отметить все», «Очистить готовые»
- Синхронизация между вкладками браузера
- Светлая и тёмная тема (по умолчанию как в системе, выбор запоминается)
- Адаптивная вёрстка для телефона
- Доступность: управление с клавиатуры, подписи для скринридеров, учёт `prefers-reduced-motion`
- Горячая клавиша <kbd>/</kbd> — фокус на поле ввода
- Число активных задач в заголовке вкладки

## Надёжность

- Текст задач выводится через `textContent`, поэтому HTML-инъекции (XSS) невозможны.
- Если данные в `localStorage` повреждены, битые записи отбрасываются, и приложение продолжает работать.
- Если хранилище недоступно (приватный режим, переполнение), задачи живут в памяти без ошибок.
- Ключ хранилища версионирован (`todo-list:v1`), чтобы в будущем безопасно менять формат.

## Структура

```
index.html          разметка и шаблон задачи
style.css           стили, темы, анимации
store.js            чистая логика: операции над задачами и работа с хранилищем (без DOM)
app.js              интерфейс: отрисовка и обработчики событий
store.test.js       юнит-тесты логики (node:test)
```

Логика отделена от интерфейса: все функции в `store.js` чистые и не изменяют исходные данные, поэтому их легко тестировать.

## Запуск

```bash
npm start   # локальный сервер на http://localhost:3000
npm test    # юнит-тесты (нужен Node.js 18+)
```

Можно запустить любым статическим сервером, например `python3 -m http.server`. Сборка не нужна.
